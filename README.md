# FUTURE_ML_01

## Future Interns – Machine Learning Internship

This repository contains the projects completed as part of the Future Interns Machine Learning Internship Program.

## Projects

### Task 1 – AI Resume Screening and Job Recommendation System
An AI-based system designed to analyze resumes and recommend suitable job opportunities based on skills, qualifications, and job requirements.

### Task 2 – Sales Demand Forecasting
A machine learning project that analyzes historical sales data and predicts future sales demand using time-based features such as Year, Month, and Quarter.

### Task 3
Machine learning project completed as part of the internship task requirements.
